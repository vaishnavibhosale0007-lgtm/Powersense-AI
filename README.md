# PowerSense AI

## IoT-Based Predictive Transformer Management System

PowerSense AI is our B.E. project focused on developing an IoT-based predictive transformer monitoring and management system.

The project aims to monitor electrical parameters, identify abnormal operating conditions, and support automated load transfer for improved power reliability.

## Project Status

🚧 B.E. Project — Currently Under Development

This repository will be updated progressively as the project development, hardware implementation, firmware development, testing, and documentation are completed.

## Objectives

- Monitor transformer electrical parameters
- Detect abnormal operating conditions
- Enable IoT-based monitoring
- Implement automated load transfer
- Explore predictive monitoring using AI/ML techniques
- Improve transformer power reliability

## Proposed Technologies

- STM32 Microcontroller
- PZEM Sensors
- MQTT
- IoT
- AI/ML
- Embedded C

## Proposed System

The proposed system consists of an STM32-based controller for acquiring and processing electrical parameters. PZEM sensors are intended to be used for electrical parameter monitoring, while MQTT is planned for IoT communication and monitoring.

The system is intended to analyze operating conditions and support automated load-transfer decisions.
